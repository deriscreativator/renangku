# RenangKu – Les Renang Online

Static HTML prototype for portfolio/demo use.

## Publish with GitHub Pages
1. Create a new **public** GitHub repository, for example `renangku-demo`.
2. Upload `index.html` (and optionally `.nojekyll`) to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main`, folder `/ (root)`, then Save.
6. Wait for GitHub Pages to publish. The public URL will look like:
   `https://YOUR-USERNAME.github.io/renangku-demo/`

## Prototype limitations
- Learning progress is stored locally in the visitor's browser.
- Video evidence upload is represented as a demo interaction; no video is uploaded to a server.
- Coach approval is simulated in demo mode.
- Video calls use Jitsi Meet room links.
- No production user accounts, central database, or admin backend are included.
